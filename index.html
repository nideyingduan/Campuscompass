使用声明

本页面为个人学习项目，非学校官方服务，与相关学校及各平台方无隶属或合作关系。

页面仅聚合公开的网络入口，方便日常访问，不涉及账号登录、自动签到、数据抓取等任何越权操作。各系统的登录与数据均归属其所属平台/学校，请遵守相应使用规则。

项目代码开源供学习交流，使用风险自负。页面中出现的名称、标识等版权归各自所有方所有。

如何添加到桌面

第 1 步：用手机自带浏览器（Safari / Chrome / 浏览器 App）打开本页面网址，不要在微信里直接添加。

· iPhone（Safari）：点底部分享按钮（方框+箭头）→ 选择"添加到主屏幕" → 点右上角添加。

· 安卓（Chrome）：点右上角 ⋮ 菜单 → 选"添加到主屏幕" / "安装应用" → 确认。

如果是在微信里打开的：先点右上角 ··· → 选"在浏览器打开"，再按上面操作。

添加后，桌面会出现"校航"图标，点开即用，登录状态也会保存在浏览器里。
